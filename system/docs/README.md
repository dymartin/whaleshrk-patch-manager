# Knowledge base

This directory records facts that cannot be recovered cheaply from the Python
application: device behaviour, upstream formats, API quirks, provenance, and
questions that still require hardware evidence.

| Document | Contents |
|---|---|
| [overview.md](overview.md) | Short description of the system |
| [platform/](platform/README.md) | ORHACK, ORAC, Organelle, and Patchstorage findings |
| [catalog.md](catalog.md) | External evidence that constrains module ingestion |
| [open-questions.md](open-questions.md) | Unknowns that still need evidence |

The code, tests, CLI help, and repository tree are authoritative for schemas,
commands, workflows, storage formats, validation, and implementation choices.
Those subjects are intentionally not duplicated here.
